# UI — Interfaz

Estado: vigente · Código: `src/ui/*`, `src/styles/app.css`

### UI-001 · Idioma y formato
Toda la interfaz está en español (es-ES); precios en EUR con `Intl` es-ES; horas `HH:MM`. El código
(identificadores, comentarios) está en inglés.

### UI-002 · Lenguaje visual
Paneles de "papel" translúcido (blur) sobre la escena, tinta `#221f1b`, acento terracota `#c4673c`,
radios 18/11 px, Fraunces (títulos) + Inter (UI). Todos los valores salen de los tokens `:root` de
`app.css`; no se añaden colores sueltos.

Chips de categoría (Asientos, Mesas, Almacenaje, Iluminación, Plantas, Objetos, Alfombras, Pared),

### UI-005 · Inspector contextual
Sin selección: «Estancia» (m², nº de piezas, presupuesto, acabados). Pieza: acciones (girar ±15°,
duplicar, encuadrar, bloquear, eliminar), tamaño, ranuras de material, luz (regulador), posición,
«Encima» (hijos). Pared: acabado + «Aplicar a todas las paredes». Suelo/Techo: acabado.
`@code src/ui/Inspector.tsx#Inspector` `@e2e`

### UI-006 · Dock

hora + icono sol/atardecer/luna, lámparas (ciclo Auto/Encendidas/Apagadas con insignia A/I/O) y
ajustes de luz: presets Amanecer 7.25, Mediodía 12.5, Atardecer 19.6, Noche 22.5; orientación

### UI-009 · Atajos de teclado
Ignorados mientras se escribe en un campo.

| Tecla | Acción |
|---|---|
| `Ctrl+Z` / `Ctrl+Mayús+Z`, `Ctrl+Y` | Deshacer / rehacer |
| `Ctrl+S` · `Ctrl+D` | Guardar · duplicar |
| `Supr`, `Retroceso` | Eliminar selección |
| `Q` / `E` · `R` | Girar +15° / −15° · +90° |
| Flechas (Mayús) | Mover 5 cm (1 cm) |
| `L` · `F` | Bloquear · encuadrar |
| `G` | Ciclo de ajuste inteligente → rejilla → libre |
| `1` `2` `3` `4` | Maqueta · Planta · Paseo · Cine (4 activa el recorrido) |
| `W A S D` | Caminar (Paseo) |
| `Espacio` | Time-lapse |
| `H` · `P` · `?` | Ocultar UI · captura · atajos |
| `Esc` | Cancelar gesto → salir de Cine → mostrar UI → deseleccionar |

`@code src/ui/App.tsx#useShortcuts` `@code src/ui/Modals.tsx#SHORTCUTS` `@e2e`

«Ocultar interfaz» en el menú, dock en dos filas.
